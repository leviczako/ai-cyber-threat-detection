# Project Summary

## Project Title

AI Cyber Threat Detection

## Overview

This project demonstrates a basic AI-based cybersecurity workflow for detecting suspicious activity in network traffic data.

The project uses a public network intrusion detection dataset and applies machine learning to classify network activity as either normal or suspicious.

## Goal

The goal of this project is to explore how artificial intelligence can support cybersecurity teams by detecting suspicious activity and presenting model outputs in a clear, human-readable format for security analysts.

## What the Project Includes

- Data exploration of a public cybersecurity dataset
- Binary classification setup:
  - `0` = normal network activity
  - `1` = suspicious or malicious activity
- Random Forest machine learning model
- Model evaluation using accuracy, classification report, and confusion matrix
- SOC-style alert summary generation

## Initial Result

The first Random Forest model achieved an accuracy of 0.9994 on the test dataset.

This result shows that machine learning can identify patterns related to suspicious network activity in a controlled public dataset.

## Important Note

This is an early portfolio project and not a production-ready cybersecurity system.

The purpose of the project is to demonstrate practical interest and basic technical ability in AI-driven cybersecurity, threat detection, and SOC automation.
